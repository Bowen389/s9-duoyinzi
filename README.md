## 模拟成交和真实资金约束

T 收盘信号用于下一交易日开盘。每日盘后取得真实未复权 OHLC 后，记账该日开盘与预先到期的收盘成交；因此上午不会显示已结算成交，盘后统一确认。无法成交的买单当日作废；到期卖单继续延期。停牌/无成交不成交，开盘封涨停不买、封跌停不卖；仅日线数据无法还原盘口队列，采用保守处理。ETF亦采用保守10%限制，特殊品种实际可不同，需评估细分规则后调整。

股票滑点每边0.15%，佣金万2.5且最低5元，过户费每边万0.1、卖税万5；ETF滑点每边0.02%、佣金万1且最低5元，无印花税。不借款、不透支。普通股票/ETF按100份整手；科创板至少200股、后续1股递增；T+1限制卖出。数据用于信号为前复权，成交与估值使用未复权价。除权除息检测到后标记 CORPORATE_ACTION_REVIEW 并暂停相关证券成交，等待核对股数/分红；估值继续使用当日原价并标识待核验，不能把未核验净值当作精确收益。普通闲置现金不虚拟计货币基金收益，未购买基金不产生基金收益。

股票 hold=3 是买入日期+3个交易日退出（含买入日共4个持仓日）。为容纳重叠批次，每日新批次预算=净资产/(hold+1)，再除TopN；hold=1则每日最多使用净资产一半。原回测的每日重叠收益平均不等于可实现的现金账本，本仓库不复用其历史收益。Top20小额整手/最低佣金会影响实际买入数与收益。

S9 每日决策以本账户实际持仓、成交成本、入场日、冷静期为输入，未继承历史回测持仓；目标集合不变时保持原引擎不重置权重的语义。

## 上传包中的问题及修复

保留原始引擎于 strategies/champion_source.py 与 s9_source.py，runner 负责上线适配。

1. 股票原信号末日会因 next-day return 缺失而整日 NaN，并自动回退旧日。涨停溢价在原实现中是全市场当日常量，其截面z-score本来就是0；上线直接用0贡献，无需未来价格，也不回退日期。
2. 换手分段归一化原先使用整个样本未来最大/最小；改为截至当日的分段累计最大/最小。因此历史报告收益不可直接当作上线绩效。
3. 原板块下载 future 返回值解包错误且不读取已有缓存；上线修复、按日期更新映射。
4. 原个股日线缓存存在后不更新；现在严格检查日期并刷新。信号数据失败时不产生新买入意图；已有预定卖出仍先按可用行情结算。
5. 原 S9 指令器从历史回测继承仓位；上线由真实模拟账本驱动决策。
